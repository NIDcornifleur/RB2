\# Module rb2\_esp32.py - 2026-06-26



\## Objectif



Ce document analyse le fichier :



\- opt/rb2/rb2\_esp32.py



Aucune modification fonctionnelle n'a été faite dans ce fichier.



Le but est de documenter le rôle du module avant tout nettoyage futur.



\## Rôle du module



rb2\_esp32.py est le module de liaison série entre le panneau Flask esp32\_panel.py et l'ESP32.



Il fournit la classe principale :



\- RB2ESP32



Cette classe sert à :



\- ouvrir le port série de l'ESP32;

\- envoyer des commandes texte terminées par un saut de ligne;

\- lire en continu les réponses série;

\- conserver les dernières lignes reçues;

\- détecter les lignes encodeurs;

\- écrire les ticks roues dans /tmp/rb2\_wheel\_ticks.json;

\- exposer une API simple utilisée par esp32\_panel.py.



Ce module est critique, car il transporte les commandes réelles vers l'ESP32.



\## Paramètres sensibles



\- port série : /dev/serial/by-id/usb-1a86\_USB\_Serial-if00-port0

\- baudrate : 115200

\- timeout série : 0.2 s

\- attente après ouverture : 2.0 s

\- fichier ticks : /tmp/rb2\_wheel\_ticks.json



Ces valeurs ne doivent pas être modifiées sans validation réelle sur RB2.



\## Commandes série principales



\- d0,0 : STOP moteur

\- dG,D : commande moteurs gauche/droite

\- pN : commande pan

\- tN : commande tilt

\- enc : lecture encodeurs

\- status : état ESP32



\## Zones dangereuses



Ne pas modifier sans test réel :



\- send()

\- stop()

\- drive()

\- pan()

\- tilt()

\- encoders()

\- \_reader\_loop()

\- \_parse\_compact\_encoder\_line()

\- \_write\_wheel\_ticks\_json()



\## STOP



La méthode stop() envoie :



\- d0,0



C'est une commande critique. Elle ne doit pas être changée.



\## Encodeurs



Le format attendu est :



\- ENC FL FR RR RL



Les ticks sont écrits dans :



\- /tmp/rb2\_wheel\_ticks.json



Ce fichier est important pour l'odométrie et les ponts ROS.



\## Pan/Tilt



Les limites appliquées dans ce module sont :



\- pan : 0 à 180

\- tilt : 68 à 145



Ces limites ne doivent pas être modifiées sans validation mécanique.



\## Conclusion



rb2\_esp32.py est une couche bas niveau courte mais critique.



Elle ne contient pas toute la logique de sécurité métier, mais elle transporte les commandes réelles vers l'ESP32.



Toute modification du protocole série, du STOP, des encodeurs ou des limites pan/tilt doit être considérée comme à haut risque.
